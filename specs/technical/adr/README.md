# Registros de decisiones de arquitectura (ADR)

Cada ADR sigue el formato de Michael Nygard: título, estado, fecha, contexto, decisión, consecuencias y alternativas consideradas.

Los ADR aceptados no se reescriben: los cambios posteriores se agregan al final como "Enmienda" con su fecha. ADR-001 a ADR-004 tienen enmiendas del 28/10/2026, y ADR-003 y ADR-004 tienen además una del 29/10/2026.
